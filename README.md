# Student Grade Calculator

## About the Project
A simple Python mini project that calculates a student's total marks, percentage, grade, and pass/fail result.

## Features
- Takes student name
- Accepts marks for multiple subjects
- Calculates total marks
- Calculates percentage
- Assigns a grade
- Displays PASS or FAIL

## Technology Used
- Python

## How to Run
1. Install Python.
2. Open the project in VS Code.
3. Run `student_grade_calculator.py`.

## Grade Criteria
- 90% and above: A+
- 80%–89%: A
- 70%–79%: B
- 60%–69%: C
- 50%–59%: D
- Below 50%: F
